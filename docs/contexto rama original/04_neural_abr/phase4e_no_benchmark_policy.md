# Phase 4E — No-benchmark policy

Phase 4E is offline training sanity, not formal evaluation.

Allowed language:

- synthetic smoke passed;
- model produced valid actions;
- offline validation did not show pathological behavior;
- external trace diagnostic result;
- candidate ready for export contract if gates pass.

Forbidden language:

- best controller;
- final ranking;
- beats BBA/MPC generally;
- real-world validated;
- SOTA;
- benchmark winner.

Any comparison in Phase 4E is diagnostic only and must be marked as such.
