# Training data contract

Project: DashClientModular4 — Phase 4 IA/RL ABR
Phase block: Phase 4B — state/action/reward/training-data contracts
Status: repo-ready contract draft generated after Phase 4A0/A1/A2.

## Purpose

This document defines what can and cannot become training data for NeuralABR-Lite.

## Allowed training data sources

Allowed by default:

```text
external network traces with documented origin
synthetic traces generated by a documented trace generator, if used only as train/validation diagnostic
converted public traces with reproducible conversion scripts
teacher labels generated offline from allowed train traces
```

Allowed only with explicit documentation:

```text
local controlled traces captured for a new data-collection protocol
public ABR benchmark traces if license and provenance are documented
```

## Forbidden training data sources

Forbidden:

```text
DashClientModular4 legacy dry-runs
QoE smokes
controller smoke scenarios
benchmark outputs
final evaluation artifacts
test traces
validation/OOD traces after hyperparameter tuning
player/runtime logs generated without a data contract
human-selected cherry-picked traces with no manifest
```

## Why dry-runs legacy are forbidden

Legacy dry-runs are outputs of a controller/player/runtime pipeline, not neutral observations of network capacity. They may encode decisions, controller behavior, artifact conventions, runtime shortcuts, or diagnostic assumptions.

Using them as training data would violate the CausalSim-inspired gate against biased trace replay and contaminate the experimental story.

## Dataset levels

A future dataset builder must distinguish:

```text
raw_trace: source network trace or converted exogenous trace
abr_episode: simulated sequence under a teacher/controller
sample: one decision point with context, candidates, mask and label
report: aggregate diagnostic output
```

Only `sample` rows generated from allowed `raw_trace` sources and train split labels may be used for model training.

## Required manifests

Any generated dataset must include:

```text
dataset_manifest.json
trace_source_manifest.json
split_manifest.json
teacher_label_manifest.json
normalization_manifest.json
feature_availability_report.json
artifact_policy_report.json
```

These artifacts remain outside the repo unless a small textual summary is intentionally committed under docs.

## Phase 4B decision

Training data must be external, trace-level split, teacher-labeled, manifest-backed and free of legacy dry-run contamination.
