# Phase 5B artifact policy

## Repository rule

Only documentation is committed in this block.

## Forbidden artifacts

Do not commit:

- model artifacts;
- PDFs;
- `.pt`;
- `.pth`;
- `.onnx`;
- `.pkl`;
- `.joblib`;
- `.npz`;
- `.npy`;
- logs;
- CSVs;
- datasets;
- checkpoints;
- run artifacts;
- zip files.

## Bundle location

The NeuralABR-Lite bundle must stay outside the repository. Future diagnostic reports should also remain outside the repository unless a later documentation block explicitly defines a small, sanitized report format.

## Phase 5B boundary

This block commits Markdown contracts only.
