# No-ranking policy

Status: closed_phase3_5_rebuild_contract.

Phase 3.5 permite:

- validar formula QoE
- calcular rewards de segmentos sinteticos
- validar gates
- generar smokes controlados
- preparar APIs para runs futuros

Phase 3.5 prohibe:

- ordenar controllers por QoE
- declarar mejor controller
- declarar ganador
- convertir smokes en benchmark
- entrenar IA
- usar dry-runs legacy como evidencia formal

Los escenarios smoke se nombran por caso fijo, no por rendimiento.
