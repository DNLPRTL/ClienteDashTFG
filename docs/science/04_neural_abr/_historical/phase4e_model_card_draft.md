# Phase 4E model card draft

## Model

- Name: NeuralABR-Lite Candidate Scorer
- Phase: 4E Tier 0 synthetic smoke
- Status: diagnostic smoke checkpoint only
- Decision: `PHASE4E_SYNTHETIC_SMOKE_PASS_READY_FOR_TRACE_DATA`

## Intended Use

This checkpoint is intended only to verify the offline training pipeline:

- synthetic dataset build;
- schema validation;
- train-only normalization;
- CPU behavior-cloning training;
- action-mask validation;
- OOD diagnostic reporting.

## Not Intended Use

- Production deployment.
- Real-world performance claims.
- Benchmark ranking.
- Controller registration.
- Phase 4F export readiness.
- Phase 5 client integration.

## Training Data

- Source: synthetic smoke traces generated by the Phase 4D offline pipeline.
- Trace schema: `normalized_trace_schema_v1`.
- Split unit: trace-level synthetic split.
- Train samples: 24.
- Validation samples: 12.
- OOD diagnostic samples: 12.
- Leakage audit: PASS, `blocked=false`.

No legacy dry-runs, QoE smokes, benchmark outputs, player logs, media segments, or external trace corpora were used.

## Features

Context features:

```text
throughput_history_bps[5]
download_time_history_s[5]
buffer_s
last_representation_index
last_bitrate_bps
recent_rebuffer_s
recent_switch_abs
chunks_remaining_norm
has_chunks_remaining
```

Candidate features:

```text
candidate_representation_index
candidate_ladder_position_norm
candidate_bitrate_bps
candidate_bitrate_norm_ladder
candidate_delta_from_last_bitrate_norm
candidate_chunk_size_bytes
candidate_chunk_size_available
```

Forbidden model inputs include trace ID, split, source dataset, future throughput, future download time, teacher action, teacher reward and benchmark results.

## Training

- Objective: masked cross entropy over candidate scores.
- Optimizer: Adam.
- Epochs: 3.
- Batch size: 8.
- Seed: 123.
- Device: CPU.
- Final loss: 1.3416582345962524.
- Mean loss: 1.3560392591688368.

## Limitations

The checkpoint is not a selected ABR model. It used only synthetic traces and showed fixed representation-3 predictions on this tiny dataset. It proves pipeline execution only, not policy quality.
