# Phase 4D artifact policy

## Repo-allowed

```text
.py source files
.md documentation
unit tests
small static test fixtures only when generated inside tests or tiny JSON literals
```

## Repo-forbidden

```text
PDFs
raw datasets
converted trace datasets
JSONL datasets
CSV datasets generated by Phase 4D
model checkpoints
ONNX files
TensorBoard logs
training logs
large binaries
```
